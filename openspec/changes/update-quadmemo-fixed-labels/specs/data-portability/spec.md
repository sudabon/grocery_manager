## MODIFIED Requirements

### Requirement: 辞書のエクスポートとインポート

辞書編集画面は、4 象限の辞書を 1 つの JSON として出力できなければならない（MUST）。出力には版数（`version`）と、象限ごとの単語リストを含めなければならない（MUST）。象限ラベルは固定値なので出力に含めてはならない（MUST NOT）。

辞書のインポートは、入力内容を検証してから適用しなければならない（MUST）。検証に失敗した場合はエラーを表示し、既存データを一切変更してはならない（MUST NOT）。インポート内容に象限ラベルが含まれていても、それを取り込んではならない（MUST NOT）。ラベルを省略した JSON と文字列ラベルを含む旧 JSON の両方を受け付けなければならない（MUST）。ラベルが存在して文字列でない場合は検証エラーとしなければならない（MUST）。

#### Scenario: 辞書をエクスポートすると復元可能な JSON が得られる

- **WHEN** 辞書編集画面からエクスポートを実行する
- **THEN** 版数と 4 象限すべての単語リストを含む JSON が受け取れる

#### Scenario: 不正な内容のインポートは何も変更しない

- **WHEN** JSON として壊れている、または必要な項目を欠く内容をインポートする
- **THEN** エラーが表示され、辞書の内容は変更前のままである

#### Scenario: 正しい辞書 JSON のインポートで単語リストが置き換わる

- **WHEN** 正しい形式の辞書 JSON をインポートする
- **THEN** 4 象限の単語リストがインポート内容に置き換わり、以後のコミットの分類に反映される

#### Scenario: ラベルを含む古い JSON をインポートしてもラベルは変わらない

- **WHEN** 象限ラベルを含む形式の辞書 JSON をインポートする
- **THEN** 単語リストだけが置き換わり、表示されるラベルは固定値のままである
