## MODIFIED Requirements

### Requirement: デプロイによる更新反映

デプロイ操作は、ビルド成果物をオリジンへ同期し、成果物に存在しないファイルをオリジンから削除し、エントリポイント資産の配信キャッシュを無効化しなければならない（MUST）。デプロイ完了後、利用者がリロードすると新しいバージョンを取得できなければならない（MUST）。

デプロイ操作は、配信先（オリジンバケットと対象ディストリビューション）を構成の出力値から解決しなければならない（MUST）。ただし、実行環境から配信先が明示的に与えられた場合は、そちらを用いなければならない（MUST）。配信先が明示的に与えられている場合、構成の出力値を参照してはならない（MUST NOT）。

デプロイ操作は、解決の経路によらず、配信先の値が想定の形式に合致することを確認しなければならない（MUST）。合致しない場合、オリジンへ一切書き込む前にデプロイを中止しなければならない（MUST）。

#### Scenario: デプロイ後にリロードで新バージョンが反映される

- **WHEN** アプリシェルの内容を変更してデプロイ操作を実行し、利用者がブラウザをリロードする
- **THEN** 変更後の内容が表示される

#### Scenario: 削除されたファイルが配信から消える

- **WHEN** ビルド成果物から削除されたファイルがある状態でデプロイ操作を実行する
- **THEN** そのファイルはオリジンからも削除され、配信されない

#### Scenario: 明示的に与えられた配信先が使われる

- **WHEN** 実行環境でオリジンバケットと対象ディストリビューションが明示的に与えられた状態でデプロイ操作を実行する
- **THEN** 与えられた配信先へ同期と無効化が行われ、構成の出力値は参照されない

#### Scenario: 形式が不正な配信先ではデプロイが中止される

- **WHEN** 想定の形式に合致しない配信先が明示的に与えられた状態でデプロイ操作を実行する
- **THEN** オリジンへの同期・削除・キャッシュ無効化のいずれも実行されずにデプロイが中止され、エラーが報告される
