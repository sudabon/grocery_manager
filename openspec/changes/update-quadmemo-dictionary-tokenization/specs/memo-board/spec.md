## MODIFIED Requirements

### Requirement: コミットテキストのチップ化

コミットされたテキストは単語単位のトークンへ分割され、トークン 1 つごとにチップ 1 つを生成しなければならない（MUST）。分割にあたり、辞書に登録された語は分割してはならず、1 つのトークンとして扱わなければならない（MUST）。句読点・記号・空白のみのトークン、および前後の空白を除去すると空になるトークンは破棄しなければならない（MUST）。チップにはコミットされた原文のトークンを表示しなければならない（MUST）。

#### Scenario: 複数単語のコミットで単語ごとのチップができる

- **WHEN** 複数の単語を含むテキストをコミットする
- **THEN** 単語ごとに 1 つずつチップが生成され、コミット順に象限へ並ぶ

#### Scenario: 辞書に登録した語は割れずに 1 つのチップになる

- **WHEN** 単語分割では複数に割れる語を辞書へ登録したうえで、その語を含むテキストをコミットする
- **THEN** その語のチップが 1 つだけ生成され、コミットした原文の表記で表示される

#### Scenario: 句読点だけのトークンは破棄される

- **WHEN** 単語と句読点を含むテキストをコミットする
- **THEN** 単語のチップのみが生成され、句読点のチップは生成されない

#### Scenario: 単語分割 API が使えない環境でもチップが生成される

- **WHEN** 実行環境が単語分割 API に対応していない
- **THEN** 空白・句読点による分割にフォールバックし、チップの生成は継続される
