## MODIFIED Requirements

### Requirement: モバイル入力時の操作性

入力欄はフォーカス時に画面が自動拡大されないフォントサイズ（16px 以上）でなければならない（MUST）。ソフトウェアキーボードが表示されている間、入力バーはキーボードに隠されてはならない（MUST NOT）。画面下部の操作エリアは端末のセーフエリア（ホームバー等）と重なってはならない（MUST NOT）。操作要素のダブルタップによる拡大、およびチップ長押しによるテキスト選択・コールアウト表示は抑止しなければならない（MUST）。

画面下部の操作エリア（入力バーとマイクボタン）はボードの下に配置し、ボードの表示領域と重なってはならない（MUST NOT）。入力バーを閉じている間、操作エリアの高さはマイクボタンと最小限の余白に収めなければならない（MUST）。ソフトウェアキーボードが表示されている間は、キーボードと操作エリアに隠れる分だけボードの表示領域を縮め、象限内をスクロールすれば末尾のチップまで全体が見えなければならない（MUST）。

#### Scenario: 入力欄フォーカスで画面が拡大されない

- **WHEN** 入力欄にフォーカスする
- **THEN** 画面の表示倍率は変わらない

#### Scenario: キーボード表示中も入力バーが見える

- **WHEN** ソフトウェアキーボードが表示された状態で入力バーを操作する
- **THEN** 入力バーと確定ボタンはキーボードの上に見えており、タップできる

#### Scenario: セーフエリアと操作エリアが重ならない

- **WHEN** セーフエリアを持つ端末でメモ画面を表示する
- **THEN** マイクボタンはセーフエリアに被らず、全体がタップできる

#### Scenario: 入力バーを閉じている間は操作エリアがマイクボタンに収まる

- **WHEN** 入力バーを閉じた状態でメモ画面を表示する
- **THEN** 操作エリアの高さはマイクボタンと最小限の余白に収まり、ボードの下端は操作エリアの直上にある

#### Scenario: 入力バーを開いても操作エリアがボードに重ならない

- **WHEN** マイクボタンをタップして入力バーを開く
- **THEN** 操作エリアが伸びた分だけボードが縮み、ボードの下端は操作エリアの直上にある

#### Scenario: あふれた象限の末尾チップが全体まで見える

- **WHEN** 表示領域を超える件数のチップを持つ象限を末尾までスクロールする
- **THEN** 末尾のチップの全体がその象限の表示領域内に見える

#### Scenario: キーボード表示中はボードが縮み操作エリアが持ち上がる

- **WHEN** 入力バーを開いた状態でソフトウェアキーボードが表示される
- **THEN** 操作エリアはキーボードの上に持ち上がり、ボードはその直上で終わる（操作エリアの裏に隠れる部分が無い）
