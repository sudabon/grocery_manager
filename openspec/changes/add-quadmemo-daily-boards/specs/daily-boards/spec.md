## Purpose

メモを日付ごとのボードという単位に分け、開いたときは常にその日のボードから始められるようにする。過去の日付のボードは読み取り専用の記録として参照できる。

## ADDED Requirements

### Requirement: 日付ごとのボード

メモは日付ごとのボードに属さなければならない（MUST）。1 つの日付に対してボードは 1 つでなければならない（MUST）。ボードのタイトルは、その日付を年月日で表したものでなければならない（MUST）。

日付の基準は JST（UTC+9）でなければならない（MUST）。端末のタイムゾーン設定によって、あるメモが属する日付が変わってはならない（MUST NOT）。

#### Scenario: メモは表示中のボードの日付に属する

- **WHEN** あるボードを表示している状態でテキストをコミットする
- **THEN** 生成されたチップはそのボードの日付に属し、他の日付のボードには現れない

#### Scenario: 端末のタイムゾーンを変えても日付が変わらない

- **WHEN** 端末のタイムゾーンを JST 以外に設定してメモ画面を開く
- **THEN** 表示されるボードの日付は JST の日付である

### Requirement: 当日ボードの自動選択

メモ画面を開いたとき、システムはその日の日付のボードを表示しなければならない（MUST）。その日付のボードがまだ無い場合は、チップが 0 件のボードを表示しなければならない（MUST）。

表示中に日付が変わっても、表示中のボードを切り替えてはならない（MUST NOT）。次にメモ画面を開いたときに当日のボードを表示しなければならない（MUST）。

#### Scenario: 日付が変わったあとに開くと白紙から始まる

- **WHEN** 前日のチップが保存されている状態で、日付が変わったあとにメモ画面を開く
- **THEN** チップが 0 件のボードが表示され、前日のチップは現れない

#### Scenario: 表示中に日付が変わってもボードは切り替わらない

- **WHEN** メモ画面を表示したまま日付が変わる
- **THEN** 表示中のボードとそのチップは変わらない

#### Scenario: 過去ボードから戻ると当日ボードが表示される

- **WHEN** 過去の日付のボードを表示したあと、メモ画面へ戻る操作をする
- **THEN** 当日のボードが表示される

### Requirement: 過去ボードの一覧と参照

システムは、チップが 1 件以上ある過去の日付を一覧として表示できなければならない（MUST）。一覧は日付の新しい順でなければならない（MUST）。チップが 0 件の日付を一覧に含めてはならない（MUST NOT）。

一覧から日付を選ぶと、その日付のボードを表示しなければならない（MUST）。表示中のボードの日付は、当日か過去かに関わらず利用者が読み取れなければならない（MUST）。

#### Scenario: 過去の日付が新しい順に並ぶ

- **WHEN** 複数の日付にチップがある状態で日付の一覧を開く
- **THEN** チップがある日付が新しい順に並び、チップが無い日付は現れない

#### Scenario: 一覧から過去のボードを表示する

- **WHEN** 日付の一覧から過去の日付を選ぶ
- **THEN** その日付のボードのチップが象限ごとに表示され、表示中の日付が読み取れる

#### Scenario: 過去のボードが無い場合の一覧

- **WHEN** 当日以外にチップがある日付が無い状態で日付の一覧を開く
- **THEN** 過去のボードが無いことが読み取れる

### Requirement: 過去ボードは読み取り専用

過去の日付のボードを表示している間、チップの追加・編集・移動・削除を提供してはならない（MUST NOT）。過去のボードに対する変更を保存してはならない（MUST NOT）。

#### Scenario: 過去のボードではチップを追加できない

- **WHEN** 過去の日付のボードを表示する
- **THEN** テキストを入力してコミットする手段が提供されない

#### Scenario: 過去のボードではチップを操作できない

- **WHEN** 過去の日付のボードでチップを選ぶ
- **THEN** 移動・編集・削除の操作は提供されない
