## MODIFIED Requirements

### Requirement: ボード画像の内容

画像は PNG でなければならず（MUST）、画面上の 4 象限と同じ配置（右上 Q1、左上 Q2、左下 Q3、右下 Q4）で、各象限のラベルと、その象限にあるすべてのチップ本文を含まなければならない（MUST）。対象は表示中のボードの日付に属するチップでなければならず、他の日付のチップを含めてはならない（MUST NOT）。画像にはそのボードの日付を年月日で含めなければならない（MUST）。チップが無い象限も、ラベルが見える空の象限として描かなければならない（MUST）。入力バーや画面ヘッダーなど、ボード以外の操作 UI を含めてはならない（MUST NOT）。

#### Scenario: チップがあるボードの画像にラベルと本文が含まれる

- **WHEN** 複数の象限にチップがある状態で画像共有を実行する
- **THEN** 受け取った画像は PNG であり、各象限のラベルとすべてのチップ本文が、画面と同じ象限配置で読み取れる

#### Scenario: チップが無いボードでも画像を受け取れる

- **WHEN** メモが 0 件の状態で画像共有を実行する
- **THEN** 4 象限のラベルが見える PNG が受け取れ、エラーにはならない

#### Scenario: 画像にそのボードの日付が含まれる

- **WHEN** チップがある状態で画像共有を実行する
- **THEN** 受け取った画像に、表示中のボードの年月日が読み取れる形で含まれる

#### Scenario: 他の日付のチップは画像に含まれない

- **WHEN** 複数の日付にチップがある状態で、ある日付のボードから画像共有を実行する
- **THEN** 受け取った画像にはその日付のチップだけが含まれ、他の日付のチップは現れない

### Requirement: 画像の受け渡し手段

システムは、組み立てた PNG を端末の共有機能で受け渡さなければならない（MUST）。共有機能が利用できない環境では、同じ PNG をダウンロードとして受け取れなければならない（MUST）。ファイル名には対象のボードの日付を JST で含めなければならない（MUST）。特定の受け渡し先アプリを指定して直接送信してはならない（MUST NOT）。

#### Scenario: 共有機能が使える環境では共有が呼び出される

- **WHEN** 共有機能が利用できる環境で画像共有を実行する
- **THEN** 対象のボードの日付を含むファイル名の PNG ファイルを含む共有が呼び出される

#### Scenario: 共有機能が使えない環境ではダウンロードで受け取れる

- **WHEN** 共有機能が利用できない環境で画像共有を実行する
- **THEN** 対象のボードの日付を含むファイル名で PNG ファイルがダウンロードとして受け取れる

#### Scenario: 過去のボードの画像は当日ではなくその日付になる

- **WHEN** 過去の日付のボードを表示した状態で画像共有を実行する
- **THEN** 受け取ったファイル名と画像内の日付は、当日ではなく表示中のボードの日付である

## ADDED Requirements

### Requirement: 過去のボードからの画像共有

過去の日付のボードを表示している間も、画像共有を提供しなければならない（MUST）。過去のボードからの画像共有は、そのボードのデータを変更してはならない（MUST NOT）。

#### Scenario: 過去のボードからも画像を共有できる

- **WHEN** 日付の一覧から過去の日付を選び、画像共有を実行する
- **THEN** その日付のチップを含む PNG が共有へ渡り、そのボードのチップは変わらない
